## Pengecualian dependency pengembangan

dengan satu advisory sedang:
[GHSA-g3hv-75wg-m249](https://github.com/advisories/GHSA-g3hv-75wg-m249).
Audit dependency produksi tidak melaporkan advisory saat pemeriksaan.

Registry melaporkan patch `>=11.0.1`. Sebagian pemanggil masih memakai API versi
3; perubahan mayor harus diuji bersama upgrade tooling. Pengecualian ini harus
tetap terlihat dalam keputusan rilis. Gunakan pola glob dari repository
tepercaya dan jalankan tooling pada CI terisolasi. Jalankan ulang kedua audit
sebelum publikasi karena advisory dapat berubah.

## Langkah rilis yang masih diperlukan

1. Push commit calon rilis dan pastikan workflow `checks` lulus pada commit itu.
2. Publikasikan tag `v0.2.1` setelah verifikasi final; workflow rilis menguji ulang
   dan membangun arsip beserta manifest/checksum.
3. Backup database tujuan, verifikasi environment, lalu deploy dan jalankan
   `pnpm release:verify https://domain-tujuan`.
4. Ganti password yang pernah terekspos pada URL atau memakai fallback lama;
   verifikasi HTTPS, cookie, dan header IP terpercaya pada hosting tujuan.

Tidak ada migrasi schema baru dibanding `v0.2.0`. Perubahan penyimpanan tata
letak menyalin revisi lama ke tema pemiliknya saat penulisan lifecycle pertama
dan mempertahankan backup lama. Kembali ke kode 0.2.0 tetap membawa kembali
masalah keamanan yang sudah diperbaiki.
