# Catatan rilis

Setiap tag `v<version>` memerlukan `docs/releases/v<version>.md`. Isinya dipakai
`scripts/package-release.mjs` sebagai `notes` pada manifest dan menjadi catatan
Release GitHub. Tulis untuk operator instalasi: perubahan yang terlihat, migrasi
yang perlu diterapkan, dan langkah manual bila ada. Jangan menyertakan kredensial,
URL privat, atau data pelanggan.
