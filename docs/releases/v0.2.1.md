# NextPress 0.2.1

Rilis perbaikan keamanan, impor/ekspor, dan verifikasi pemulihan data.

## Keamanan

- Login mengirim kredensial melalui POST, termasuk sebelum JavaScript siap atau
  saat JavaScript dimatikan. Form native tetap memakai CSRF/rate limit Better Auth.
- Hilangkan password/email bawaan, argumen password CLI, dan output password dari
  skrip reset admin. Reset mencabut sesi tanpa mengubah peran/status akun.
- Tolak pengubahan akun yang lebih berkuasa oleh peran kustom pengelola pengguna.
- Batasi percobaan password profil secara atomik dan cegah penimpaan kredensial
  yang berubah selama permintaan berlangsung.
- Gunakan satu header IP terpercaya untuk autentikasi, komentar, dan views.
- Perketat referrer admin/auth dan penyaringan secret/artefak dalam paket rilis.

## Impor, ekspor, dan pemulihan

- Batas impor XML konsisten 4 MB pada UI dan server. Berkas terlalu besar ditolak
  di browser sebelum dikirim. Pecah ekspor yang lebih besar menjadi beberapa berkas.
- Batas 1.000 pos/laman WXR dan 2.000 pos/laman Blogger sekarang menghasilkan
  pesan galat; impor tidak lagi memotong daftar diam-diam.
- Impor WXR melewati tipe selain pos/laman, mempertahankan entity XML dan CDATA,
  serta ekspor menyertakan tag dan menangani karakter penutup CDATA dengan benar.
- Jelaskan bidang yang benar-benar didukung: impor WXR belum membawa komentar,
  media, bidang kustom, kategori, atau tag. Ekspor WXR bukan backup instalasi lengkap.
- Tambahkan tes browser alur editorial, media, impor/ekspor, tema, dan plugin;
  tes migrasi database berisi data, backup/restore, serta pemeriksaan hosting baca-saja.

## Open source

- Tambahkan GPL-3.0-only dan kebijakan pelaporan keamanan.
- Ganti Google Sans dengan Inter berlisensi OFL dan monospace sistem.
- CI dan workflow rilis menjalankan tes keamanan, browser, pemulihan data,
  pemeriksaan migrasi dan audit dependency produksi.

## Tindakan operator

1. Ganti password yang pernah muncul di URL atau pernah menggunakan fallback
   skrip reset lama. Membersihkan URL tidak menghapus salinan pada history/log.
2. Set `NEXTPRESS_CLIENT_IP_HEADER` sesuai header yang ditimpa proxy dengan satu
   IP terpercaya; default `x-real-ip`, Vercel `x-forwarded-for`. Tutup akses publik
   langsung ke port aplikasi di belakang proxy.
3. Backup database sebelum memperbarui. Jalankan `pnpm db:migrate`,
   `pnpm db:check`, lalu build dengan environment hosting tujuan.
4. Setelah deploy, jalankan `pnpm release:verify https://domain-anda.example`.

Tidak ada migrasi database baru dibanding 0.2.0. Pemulihan kode ke 0.2.0
mengembalikan masalah keamanan yang diperbaiki di sini, walaupun skemanya sama.

Audit penuh masih mencatat advisory `GHSA-vfj7-8cjw-p6xm` pada `braces` melalui
tooling lint. Audit dependency produksi bersih saat verifikasi; pantau patch
upstream dan jangan berikan pola glob tak tepercaya kepada tooling.
